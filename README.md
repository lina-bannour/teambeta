# # Team Beta – Personal Portfolio Website

## About the Project

Team Beta is a collaborative web development project created by four engineering students.

The project consists of a shared home page introducing the team and individual portfolio pages where each member presents their academic background, technical skills, projects, experiences, and contact information.

## Technologies Used

- **HTML** – Structure and content of the pages.
- **CSS** – Styling and visual design.
- **Bootstrap 5** – Responsive layouts and components.


## Website Features

- A shared home page introducing Team Beta.
- Individual portfolio pages for each team member.
- Consistent design and navigation across the website.
- Education and academic background sections.
- Technical skills and personal projects.
- Experience and extracurricular activities.
- Contact information and LinkedIn links.
- Responsive design for different screen sizes.

## How to Run the Project

No installation or backend is required.

1. Clone the repository:

   ```bash
   git clone https://github.com/lina-bannour/teambeta.git
   ```

2. Open the downloaded project folder.
3. Open `home.html` in your web browser.
4. Navigate through the website to explore each portfolio.

## Project Objective

The main objective is to practice front-end web development, understand how HTML, CSS, and Bootstrap work together, and gain experience working collaboratively with Git and GitHub.
